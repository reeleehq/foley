foley.agent.mcp#

The MCP surface — foley’s façade as agent-callable tools (py2mcp, #12, report 05/10).

Exposes the SELECT→preview→WEAVE loop to an LLM agent (or any MCP client) as a set of JSON-safe tools built with py2mcp (mk_mcp_server over stdio). The single rule: tools take/return only JSON (ids, scores, license summaries, timeline dicts, store keys) — never a Candidate, a WeaveResult, or numpy audio. Heavy objects stay server-side; audio is referenced by a byte-store key.

The tool functions are thin wrappers over the existing façade (a single seam, three surfaces: Python / CLI / MCP): they resolve the shared foley.index.SoundLibrary and per-session foley.agent.session.SessionStore (both injectable for tests). py2mcp / fastmcp are imported LAZILY inside build_mcp_server() only, so import foley and import foley.agent stay dol-only.

foley.agent.mcp.build_mcp_server(*, library=None, session='default', runtime=None, byte_store=None, include=None, name='foley', max_usd=None)[source]#

Build the foley MCP server (lazy py2mcp); registers the JSON-safe tool surface.

Validates that every source declares a data_egress (fail-closed), binds the injectable library / runtime / byte-store, and hands the resolved tool functions to py2mcp.mk_mcp_server. Never starts a server or touches the network.

Parameters:

  • library – The foley.index.SoundLibrary (default: the shared one).

  • session (str) – The default session id.

  • runtime – A foley.runtime.RuntimeConfig (default: the active one).

  • byte_store – A MutableMapping[str, bytes] for previews / rendered mixes.

  • include (Optional[list[str]]) – Optional subset of tool names to expose.

  • name (str) – The MCP server name.

  • max_usd (Optional[float]) – The server’s cumulative spend cap across every paid tool call, for its lifetime (default foley.cost.default_max_usd(): $1, or $3 under $FOLEY_LLM=anthropic).

Returns:

A fastmcp.FastMCP server.

foley.agent.mcp.foley_generate(prompt, backend='auto', commercial_ok=True, session='default')[source]#

Generate a sound from a text prompt (local backends only when offline).

backend='auto' tries the host’s generation order (ElevenLabs direct first, then the fal backends, then the local Stable Audio Open; the paid ones only when the host opted in with $FOLEY_GENERATE_PAID=1; $FOLEY_GENERATE_ORDER / $FOLEY_GENERATE_BACKEND change it), skipping what is not configured or not allowed offline; name one to choose (fal_stable_audio_3, elevenlabs, …).

A clip QC would quarantine for a clipped run just over the gate is repaired and stored (the repair is in the result’s notes). A refused generation’s dict carries cache_key: where its paid bytes are in the generations cache (foley.generations.get(cache_key), on the host — bytes never travel over MCP).

Return type:

dict

foley.agent.mcp.make_http_app(*, auth, path='/mcp', json_response=False, library=None, runtime=None, byte_store=None, include=None, name='foley')[source]#

Build a bearer-auth-gated ASGI app serving the foley MCP tools over streamable HTTP.

HTTP exposes the tool surface to the network, so auth is **required and fail-closed**: pass auth={'bearer_tokens': [...]} (a non-empty iterable of accepted tokens) — a request without a matching Authorization: Bearer <token> header gets a 401. The returned app (a Starlette/ASGI callable) mounts in any ASGI host (uvicorn, gunicorn, a parent FastAPI). py2mcp / fastmcp are imported lazily inside build_mcp_server(), so import foley stays dol-only.

Parameters:

  • auth (dict) – {'bearer_tokens': [...]} — required; empty/missing raises (fail-closed).

  • path (str) – The MCP HTTP mount path.

  • json_response (bool) – Return a single JSON response instead of an SSE stream (simple clients).

  • name (str) – As build_mcp_server().

Returns:

An ASGI application (the bearer-gated MCP HTTP app).

Raises:

ValueError – If auth carries no bearer tokens (no anonymous HTTP access).
