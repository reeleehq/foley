foley.audio#

Audio I/O and DSP primitives for foley.

The foundation every other foley layer decodes/encodes/transforms audio through. It commits to a small, explicit set of representations (report 09):

  • Working (in RAM, between DSP ops): a float32 NumPy array at 48 kHz — shape (frames,) mono or (frames, channels). This is the lingua franca of soundfile/librosa/soxr and exactly what CLAP expects.

  • Archive (bytes at rest): FLAC, source sample-rate and bit-depth preserved — lossless, ~40-60% smaller than WAV, self-describing.

  • Delivery / preview (derived): Opus by default (not implemented in the foundation — an FFmpeg/foley[ffmpeg] concern surfaced later).

Design rules honoured here:

  • Zero-dep import. This module imports only the stdlib at top level; the heavy libraries (numpy, soundfile, soxr, librosa, the mixing.loudness meter) are lazy-imported inside the functions that need them, so

    import foley.audio always succeeds on a bare install and only the function you call pays for (and requires) its dependency.

  • No magic numbers. Every default (sample rate, dtype, archive subtype, resample quality, trim/fade/loudness targets) is a named module-level constant used as a keyword-only argument default.

  • Never bundle FFmpeg / pydub / torchaudio. MP3/AAC/Opus transcode is an optional external-tool concern, not part of this royalty-free core.

All ops assume the working representation (float array, time on axis 0). load is the one function that produces it from arbitrary sources (path, raw bytes, or a file-like object).

foley.audio.integrated_lufs(samples, sample_rate, *, min_block_s=0.4, meter=None)[source]#

Integrated loudness (LUFS, BS.1770-4) of samples; -inf when too short to gate.

The one measurer loudness_gain_db() and the WEAVE master share. The length guard uses math.ceil (not int(round)) to mirror pyloudnorm’s float threshold n < block_size*rate at every sample rate, including rates where 0.4*sr is not integral; identical to int(round) at all standard (÷5) rates.

meter (default DEFAULT_METER) picks the BS.1770 implementation (see Meter); the too-short guard stays here, outside the meter, so every meter sees the same clips.

Lazy dependency: mixing.loudness (see loudness_component()).

Return type:

float

foley.audio.limit_true_peak(samples, sample_rate, *, ceiling_dbtp=-1.0, oversample=None)[source]#

Attenuate samples so their inter-sample true peak sits at or below ceiling_dbtp.

A static gain — the whole clip is turned down by one factor, never boosted — which is transparent and exactly what a Tier-0 range fault needs: after it, a flat-topped run or an over-ceiling peak is no longer at full scale. It is not a dynamic look-ahead limiter (that is mixing.loudness.limit_peaks(), the WEAVE master’s default), so the distortion of a heavily clipped clip stays in the waveform; that is why foley.repair applies it only to a clip just over the clipping gate.

Parameters:

  • samples (ndarray) – Working array (mono or multichannel).

  • sample_rate (int) – Sample rate in Hz (passed to the true-peak measurement).

  • ceiling_dbtp (float) – The true-peak ceiling in dBTP (default: foley’s -1 dBTP).

  • oversample (Optional[int]) – Oversampling factor for the true-peak estimate (default: the QC table’s true_peak_oversample).

Return type:

tuple[ndarray, float]

Returns:

(attenuated, gain_db). gain_db is 0.0 — and samples comes back as is — when the clip is already under the ceiling or is silent.

Lazy dependency: numpy (via foley.qc.true_peak_dbtp()).

foley.audio.loudness_gain_db(samples, sample_rate, *, target_lufs, peak_ceiling_dbfs=-1.0, short_peak_dbfs=None, max_boost_db=None, min_block_s=0.4, gate_floor_lufs=-70.0, silent_peak_dbfs=-80.0, meter=None)[source]#

The one loudness-gain rule: (gain_db, measured_lufs) to bring a clip to a target.

The policy for short, near-silent and high-crest clips lives here, and loudness_normalize() and foley.level.reference_gain_db() both apply it:

  • a silent (peak at or under silent_peak_dbfs) or non-finite clip: 0.0;

  • integrated loudness (BS.1770-4, gated) at or under gate_floor_lufs: near-silent, 0.0 (flag, don’t amplify);

  • a clip shorter than one gating block (min_block_s) cannot be measured (measured = -inf): with short_peak_dbfs it is levelled by its sample peak to that level, without it 0.0;

  • otherwise target_lufs - measured;

and a non-zero gain is capped so the sample peak stays at or under peak_ceiling_dbfs (a high-crest clip is held back) and, when max_boost_db is given, the boost at that many dB. meter swaps the loudness measurer (see Meter). Pure and deterministic.

Return type:

tuple[float, float]

Returns:

(gain_db, measured_lufs); measured_lufs is -inf for a clip too short to measure, a value at or under LUFS_GATE_FLOOR for a near-silent one.

Lazy dependencies: mixing.loudness (+ numpy).

foley.audio.loudness_normalize(samples, sample_rate, *, target_lufs=-16.0, peak_ceiling_dbfs=-1.0, min_block_s=0.4, meter=None)[source]#

Loudness-normalize to target_lufs, then keep it peak-safe.

Integrated loudness is measured (ITU-R BS.1770-4 / EBU R128), the signal is scaled to target_lufs, and finally attenuated so its sample peak sits at or below peak_ceiling_dbfs: the gain is loudness_gain_db(). Inputs are returned unchanged (flag them, don’t amplify) when silent or non-finite, near-silent (measured loudness at or below LUFS_GATE_FLOOR), or shorter than one BS.1770 gating block (min_block_s) — which a gated meter cannot measure (routine for one-shots: clicks, blips, gunshots).

Parameters:

  • samples (ndarray) – Working array (mono or multichannel, time on axis 0).

  • sample_rate (int) – Sample rate in Hz.

  • target_lufs (float) – Desired integrated loudness (default = foley’s podcast target).

  • peak_ceiling_dbfs (float) – Sample-peak ceiling (dBFS) applied after loudness normalization. Note this is a sample-peak limit, not an inter-sample true-peak (dBTP) limit — see foley.qc.true_peak_dbtp() for the oversampled measurement.

  • min_block_s (float) – Minimum clip length (seconds) that can be loudness-measured; shorter clips are returned unchanged with measured = -inf.

  • meter (Union[str, Callable[[ndarray, int], float], None]) – A Meter (default DEFAULT_METER).

Return type:

tuple[ndarray, float]

Returns:

(normalized, measured_input_lufs). When the input is near-silent or too short to measure, normalized is the unchanged input and measured_input_lufs is at or below LUFS_GATE_FLOOR (-inf for the too-short case).

Lazy dependencies: mixing.loudness (+ numpy).

foley.audio.trim_silence(samples, sample_rate, *, top_db=30.0)[source]#

Strip leading/trailing silence, returning the clip and its kept span.

Silence detection runs on a transient mono down-mix (so librosa’s time-last convention never clashes with foley’s time-first (frames, channels) layout); the returned sample indices then slice the original array along axis 0, preserving its channel layout.

Parameters:

  • samples (ndarray) – Working array (mono or multichannel).

  • sample_rate (int) – Sample rate in Hz (kept in the signature for API symmetry; trimming is index-based).

  • top_db (float) – A frame is silent when it sits at least this many dB below the reference (peak) level.

Return type:

tuple[ndarray, tuple[int, int]]

Returns:

(trimmed, (start_sample, end_sample)). On all-silent (or otherwise degenerate) input the original array is returned unchanged with a full-length span (0, len(samples)).

Lazy dependency: librosa.
