foley.cost#

Cost: what a call will cost before it is made, and a cumulative cap on a run (#57).

Three pieces, each small:

  • Pricing as data. Each source declares SOURCE_CONFIG['pricing'] — the falaw convention (unit, amount_usd, plus the source and seen date the price was read from). estimate_call() turns it into dollars for one call, and returns None — never 0.0 — when the cost cannot be known (no pricing, or a per-second price with no duration and no maximum).

  • A run-scoped budget. spend_scope() makes a Budget the active one for a find / score /

    generate run; authorize() is called before every paid call and refuses the first one that would take the run past max_usd (default default_max_usd():

    DEFAULT_MAX_USD, $1 — maintainer decision on #57 — or, when the caller chose

    a paid LLM for the SELECT rungs, DEFAULT_MAX_USD_BY_LLM, #88), or whose cost is unknown unless the budget approves unknown costs.

  • Two errors. BudgetExceeded and its subclass CostApprovalRequired.

Stdlib-only.

foley.cost.DEFAULT_MAX_USD_BY_LLM: dict[str, float] = {'anthropic': 3.0}#

The default cap of a foley.find() run whose LLM rungs the caller chose to pay for (llm= or $FOLEY_LLM), keyed by provider. With the defaults (6 events, k=10, verify='listen') Claude’s upper bound is about $2.52, so the $1 cap would refuse every such run before its first call; $3 lets it run and still caps it. A run usually spends far less than its bound (#88). Budget(max_usd=...) overrides it.

foley.cost.authorize(estimate_usd, *, what)[source]#

Admit a paid call: every budget in force must afford it, and each reserves it.

The reservation is atomic per budget, so concurrent calls cannot all pass before any is counted. Call settle() afterwards with the actual cost when known; a call that fails after being sent keeps its reservation (it may have been billed); one refused before sending is released with release().

Raises:

  • CostApprovalRequired – If estimate_usd is None and a budget in force has not approved unknown costs (Budget.approve_unknown_cost / $FOLEY_APPROVE_UNKNOWN_COST).

  • BudgetExceeded – If a budget’s spend plus estimate_usd exceeds its max_usd.

Return type:

None

foley.cost.estimate_call(config, **affordances)[source]#

The USD cost of one call to the source config declares, or None if unknown.

config['pricing'] units:

  • 'free' (local inference, a free API tier) → 0.0;

  • 'per_call' → amount_usd;

  • 'per_second' → amount_usd × the requested duration; when none is requested, × the native_defaults['duration_default_s'] the adapter sends in its place, else × native_defaults['duration_max_s'] (the duration is left to the backend: an upper bound), else None.

Parameters:

  • config (dict) – A SOURCE_CONFIG.

  • **affordances – The canonical affordances of the call (duration, …).

Return type:

Optional[float]

foley.cost.scoped_iter(iterator_factory, budget=None)[source]#

Iterate iterator_factory() with budget in force only while it runs.

A generator that holds a spend_scope() across yield would leave its budget active in the caller’s context between items (so the caller’s own calls, or another interleaved stream, would charge it). This re-enters the scope for each step and leaves it before handing the item out; closing the stream closes the inner iterator inside the scope too.

foley.cost.spend_scope(budget=None)[source]#

Put budget in force for the block; every enclosing budget stays in force too.

Budgets stack: a paid call must fit every budget in force (so an explicit, stricter budget inside a find / score run still applies) and is charged to each of them once. With no budget: inside a run, nothing changes; outside one, a fresh default Budget is used ($1).

Yields:

The innermost budget in force.
