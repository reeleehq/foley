foley.embedded_metadata#

What a pro sound file says about itself: Broadcast-WAV bext and iXML (#228).

Commercial packs (BOOM, Pro Sound Effects, Sonniss GDC) describe each file inside it: the EBU Broadcast-WAV bext chunk (Description, Originator, the origination date) and an iXML chunk whose <USER> block carries the Soundminer / UCS fields (CATEGORY, SUBCATEGORY, CATID, FXNAME, DESCRIPTION, KEYWORDS, LIBRARY, MANUFACTURER, …). read_embedded_metadata() reads both with the standard library and returns foley’s view of them:

{"caption": ..., "tags": [...], "ucs_catid": ..., "fx_name": ..., "library": ...,
 "manufacturer": ..., "raw": {"bext": {...}, "ixml": {...}}}

Only the fields the file has are present. A file that is not a RIFF / RF64 / BW64 WAVE, or has neither chunk, gives {}; a missing file raises FileNotFoundError.

FIELDS is the one table between the chunks and foley’s names, both ways: each Field has a canonical write location (where an exporter puts the value, and where a reader looks first) and ordered read_also fallbacks, plus the decode / encode pair between the stored text and foley’s value. fields_from_chunks() and chunks_from_fields() are its two directions, so the writer of #231 reuses the table rather than inverting it. The names are foley’s (caption, tags, ucs_* as on SoundRecord / SoundEvent, fx_name as on the UCS filename parse).

This module sits beside foley.audio rather than in foley.index: it is file-format I/O that both ingest (reading) and export (writing) use, stdlib-only.

foley.embedded_metadata.iter_riff_chunks(f, *, forms=(b'RIFF', b'RF64', b'BW64'))[source]#

(chunk_id, offset, size) for each top-level chunk of a RIFF / RF64 / BW64 WAVE.

Walks the chunk headers with seeks, never reading the audio, so a large file costs a few small reads. Stops quietly at a truncated chunk. For RF64 / BW64, a data chunk sized 0xFFFFFFFF takes its real size from ds64’s dataSize.

>>> import io
>>> body = b"WAVE" + b"abcd" + struct.pack("<I", 1) + b"x\0"
>>> wav = io.BytesIO(b"RIFF" + struct.pack("<I", len(body)) + body)
>>> list(iter_riff_chunks(wav))
[(b'abcd', 20, 1)]

Iterator[tuple[bytes, int, int]]
