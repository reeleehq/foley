foley.eval.external_fidelity#

Set-level fidelity from a reference toolkit run in its own interpreter (#48, #262).

foley.eval.fidelity has the FAD and KAD math in pure numpy. For numbers comparable with published ones, the reference toolkits (fadtk for FAD, kadtk for KAD) must do the embedding, the audio loading and the statistics, and both pin numpy<2 and an old torch, so neither can share foley’s environment. ExternalFidelity is the part they share, the way foley.external is for MFA and aeneas: the two wav sets are written as mono 16-bit WAVs to a temporary directory, the toolkit’s interpreter runs foley.eval.toolkit_driver on them, and its JSON answer becomes a FidelityResult stamped with the toolkit and its version. Nothing from either toolkit is imported here.

A toolkit is a subclass that sets the class attributes (its name, metric, model table, interpreter variable, install line) and says how many embedding frames each set needs (ExternalFidelity.frames_needed()); see foley.eval.fadtk and foley.eval.kadtk.

class foley.eval.external_fidelity.ExternalFidelity(*, python=None, model=None, models=None, workers=1, env=None, timeout=None, runner=<function run>)[source]#

Bases: object

A set-level fidelity score computed by a toolkit in a separate interpreter.

Subclasses set toolkit, metric, default_models, default_model, python_env, install (and optionally failure_hints), and implement frames_needed(); options() adds toolkit-specific entries to the driver’s spec, and check_clip() refuses a clip the toolkit cannot embed before anything runs.

Parameters:

  • python (Optional[str]) – An interpreter with the toolkit installed, usually in its own venv (default: $<python_env>; neither set raises with the install line).

  • model (Optional[str]) – A key of models (default default_model).

  • models (Optional[Mapping[str, tuple[str, tuple]]]) – Model name → (loader class in <toolkit>.model_loader, its args) (default default_models).

  • workers (int) – The toolkit’s embedding worker processes (each loads the model).

  • env (Optional[Mapping[str, str]]) – Variables added to this process’s environment for the program, e.g. {"TORCH_HOME": ...} to choose where the weights are cached.

  • timeout (Optional[float]) – Seconds before the run is abandoned (default: none).

  • runner (Callable[..., CompletedProcess]) – Runs the command (default subprocess.run).
