foley.eval.taste#

The “tasteful weave” eval: does a sound designer produce a restrained, clean, well-placed result?

Runs a designer (passage -> ScoreResult) over a fixed passage set and REPORTS, per passage and aggregated, the four things #45 asks of a tasteful design (report, never a gate):

  • restraint: sounds per sentence, under the ceiling of SOUNDS_PER_SENTENCE_BAND per passage and inside the band over the whole set;

  • licence cleanliness: the share of placed sounds foley.keep() accepts under the intended use (target LICENCE_CLEAN_TARGET, i.e. 100%); a sound with no library record is unclean (fail-closed, the same lookup the weave’s rights gate uses);

  • placement sanity: each placed sound starts within PLACEMENT_TOLERANCE_S of where its cue says (its trigger word, less its pre-roll, clamped at 0 as the render does). The trigger is read from SELECT’s symbolic anchor ("on 'door'"), which edits never erase, and resolved against the timeline’s word anchors (word_timeline). What it can and cannot catch: it resolves the cue with the same resolver (resolve_placement()) and the same word timings the weave used, so an unedited cue passes by construction and inherits that resolver’s false matches (#257). So each row also says how its cue matched (match: exact / stem / fuzzy / fallback / absolute, #263) and the summary counts them: a fuzzy cue may sit on the wrong word, a fallback one on none. What it catches is everything else: a nudged or absolute-pinned sound, a cue word that is never spoken, a spot effect with no cue. Word timings from the fake aligner (evenly spaced estimates, the default without foley[align]) are flagged aligned=False;

  • loudness: the woven mix’s integrated LUFS, re-measured, vs the master target, within LOUDNESS_TOLERANCE_LU (only for passages that carry narration audio).

The designer seam: the default, score_designer(), is foley.score over the Ring-0 wav fixture with the deterministic fake LLM and generation off, so the eval runs offline in CI. The point of the harness, though, is the agent-driven designer: a fresh agent with only foley and the shipped foley-sound-design skill (foley.install_agent_kit(dest)) given one passage and asked for a sound design. Plug it in as any callable that returns a ScoreResult; the metrics read only .timeline and .weave, so an agent that hands back timeline JSON is wrapped as ScoreResult(timeline=SoundDesignTimeline.from_dict(d), events=[]). Pass the library that agent drew from, so the licence check judges the same records. It is never run in tests.

Fit (“is this the right sound?”) is not re-judged here: that is run_fit_eval().

One row per enabled item of a hydrated timeline: expected vs actual onset.

The expected onset is the trigger less the item’s pre-roll, clamped at 0 exactly as the render clamps it (so a sound cued on the first word is not read as pre-roll late). An item with no trigger is ok=False (trigger_s=None): a spot effect must hang on a word. See PLACEMENT_CAVEAT for what this can and cannot catch.

foley.eval.taste.run_taste_eval(passages=None, *, designer=None, library=None, intended_use=None, thresholds=TasteThresholds(sounds_per_sentence=(0.1, 1.0), licence_clean_target=1.0, placement_tolerance_s=0.25, loudness_tolerance_lu=1.0))[source]#

Run designer over passages and report restraint / licence / placement / loudness.

Report-only: nothing here fails a build. A passage whose designer raises is recorded with its error and left out of the aggregates; a malformed passage set is refused up front (ValueError naming every bad passage), and a metric bug raises.

Parameters:

  • passages (Union[None, str, Path, Iterable]) – The passage set: None (the shipped set), a JSON path, or an iterable of Passage / {id, segments, audio?} dicts.

  • designer (Optional[Callable[[Passage], ScoreResult]]) – passage -> ScoreResult (default: score_designer() over library).

  • library – The library the designer draws from, used for the licence check. Default: eval_library() with the default designer, else foley’s default library.

  • intended_use – The rights intent (default: commercial publishing, as foley.score).

  • thresholds (TasteThresholds) – A TasteThresholds (default: the module constants); echoed in the report.

Return type:

TasteReport

Returns:

A TasteReport (to_dict() for JSON, to_markdown() for people).

foley.eval.taste.score_designer(*, library=None, intended_use=None, llm='fake', generate=False, aligner=None, **score_kwargs)[source]#

A designer that is foley.score on a passage’s segments (and audio, when it has some).

Defaults are the offline, deterministic ones: the fake LLM, no generation fallback (Budget(allow_generate=False, max_usd=0)) and the fake aligner (even with foley[align] installed), so nothing is fetched, generated or paid and runs repeat. generate=True, llm=None ($FOLEY_LLM) and a real aligner give the production behaviour.

Return type:

Callable[[Passage], ScoreResult]
