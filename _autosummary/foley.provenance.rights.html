foley.provenance.rights#

Export a sound with its rights and provenance, for a store outside foley (#66).

export_sound() returns (bytes, rights, provenance):

  • rights is a plain dict keyed by the field names of lacing.Rights (pinned to an’s AssetSource: provider, id, title, license, license_url, attribution, source_page_url, author, author_url, cacheable), so a consumer validates it with lacing.Rights(**rights). foley never imports lacing (it pulls pydantic), so the dict is the contract.

  • provenance is what Rights has no field for and a consumer must not lose: foley’s id, the sha256 of the archived bytes AND of the exported bytes (a FLAC archive re-encoded to WAV hashes differently, so both are kept to chain them) and whether the re-encode was lossless, the eight licence flags (ai_training_ok, revenue_cap_usd, …), a required notice, excluded territories, the safety flags, the edit lineage and, for an AI-generated clip, its EU AI Act Art. 50 checklist with the generation block.

Two rules carry the rights:

  • Licence codes are what a consumer classifies, from the SSOT consumers import (foley.licensing.consumer_license_code()): cc0-1.0, cc-by-4.0, stability-community, and None – UNKNOWN, never unencumbered – when the rights are unverified (a Public Domain Mark is a claim, not a grant) or unknown. An edit is exported under the most restrictive licence of its lineage (foley.licensing.rights_license_id()), so it never reads wider than a source. A provider-terms licence names the terms’ owner as provider (foley.licensing.LICENSE_TERMS_PROVIDER), since a consumer reads such a code only on that provider’s source.

  • The export is fail-closed: bytes foley may not keep (cache_bytes_ok=False, a Freesound API pull stored by reference) are not handed to another store either (foley.licensing.export_refusal()), and bytes are exported only when they match the content hash their record names.

Everything is read off the LicenseRecord SSOT through the credits layer (title, author, licence URL, attribution line); no flag is re-derived.

The export also interoperates with library tools (Soundminer, Soundly, BaseHead; #231):

  • a UCS filename (CatID_FXName_CreatorID_SourceID_<foley id>.wav, export_ucs_filename()) goes in provenance["filename"], a suggestion the

    consumer may use. It is not a fourth return value: (bytes, rights, provenance) is the contract callers unpack, and the provenance already describes the exported bytes (format, subtype, hash).

  • a WAV export carries its description in bext / iXML (export_metadata(), written by foley.embedded_metadata.write_embedded_metadata()): caption, tags, the UCS fields, and the licence, licence URL and attribution line of rights, so the credit travels with the file. The samples are untouched and provenance["sha256"] is taken after embedding, so it names the bytes returned.

foley.provenance.rights.export_sound(sound_id, fmt='wav', *, library=None, subtype=None, embed_metadata=True, ucs_filename=True, ucs_table=None)[source]#

Export a sound’s bytes as fmt with its rights and provenance (#66, #231).

The sound’s bytes are fetched from library, checked against the record’s content hash, and re-encoded (foley.audio.transcode(): PCM, the archive’s own depth where fmt allows, so a PCM_24 FLAC gives a sample-exact PCM_24 WAV; bytes already in fmt and subtype are not re-encoded). A WAV then gets its bext / iXML metadata (export_metadata()).

Parameters:

  • sound_id (str) – The record id in library.

  • fmt (str) – The container to export (any libsndfile format: 'wav', 'flac').

  • library (Optional[SoundLibrary]) – The SoundLibrary to read (default: foley.default_library()).

  • subtype (Optional[str]) – The sample format (default: foley.audio.export_subtype()).

  • embed_metadata (bool) – Write bext / iXML into a WAV export (default on: it adds chunks only, never touches the samples, and makes the file carry its own credit; other formats, and a WAV the writer refuses, such as a streamed one sized 0xFFFFFFFF, are left as encoded, with a note). The licence fields (EXPORT_OWNED_FIELDS) are foley’s: a source file’s value is removed when rights has none.

  • ucs_filename (bool) – Put the UCS filename in provenance["filename"] (default on: it is only a suggestion, so it costs a consumer nothing to ignore). The embedded UCS fields do not depend on it: they follow embed_metadata.

  • ucs_table (Optional[UcsTable]) – The UCS table the CatID is resolved in (default: foley.index.taxonomy.default_ucs_table()).

Returns:

rights from sound_rights(), provenance from sound_provenance(), plus filename (the UCS filename, or None), embedded (the chunks written: ['ixml', 'bext'], or []) and export_notes (why a filename or chunks are missing, and what of a source file’s own metadata was not kept). provenance["sha256"] is the hash of the bytes returned.

Return type:

tuple[bytes, dict, dict]

Raises:

  • KeyError – sound_id is not in library.

  • LicenseRefusal – the sound’s terms forbid keeping its bytes (cache_bytes_ok=False).

  • LookupError – the bytes are not available locally.

  • ValueError – the record names no content hash, or the bytes no longer match it.

foley.provenance.rights.export_ucs_filename(record, rights, *, ext='wav', table=None, fx_name_max_chars=25)[source]#

The UCS filename of record’s export, or None when it has no CatID in table.

CatID_FXName_CreatorID_SourceID_UserData.ext: the CatID is record.ucs_category (which holds the CatID), looked up in table (default: foley.index.taxonomy.default_ucs_table()); the FXName is the caption (else the tags) cut to fx_name_max_chars; the creator is rights’ author, else its provider; the source is foley’s source name; the UserData is the foley id (id_to_user_data(): injective, case-safe, reversible), so two exports of one library never share a name. The other blocks are cut to fit the filename limit (UCS_NAME_MAX_BYTES); the id is never cut. parse_ucs_name() reads it back.

Raises:

ValueError – the id alone does not fit in a filename.

Return type:

Optional[str]

foley.provenance.rights.id_to_user_data(sound_id)[source]#

sound_id as a filename block, injectively: id_from_user_data() inverts it.

Every character but lower-case ASCII letters, digits, - and ~ is percent-encoded (its UTF-8 bytes, upper-case hex), so the block holds no _, ., path or reserved character, and two ids never give names that differ only in case (which a case-insensitive filesystem, macOS or Windows, would merge).

>>> id_to_user_data("fs:1_A.b"), id_from_user_data("fs%3A1%5F%41%2Eb")
('fs%3A1%5F%41%2Eb', 'fs:1_A.b')
Return type:

str

foley.provenance.rights.sound_rights(record)[source]#

record’s rights as a dict keyed by lacing.Rights field names.

license is rights_license_id() as a consumer code (the most restrictive licence of an edit’s lineage), license_url that licence’s. attribution is foley’s plain-text credit line, so it carries the (modified) notice, the AI disclosure (AI-generated with <model>) and an edit’s sources. author is None when no creator or rights holder is recorded (the credit line falls back to the source name; a rights record does not).
