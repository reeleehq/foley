foley.sources.edit#

Edits of a sound (#162): audio-to-audio, inpaint, extend — the parts an edit adds to generation.

An edit is a generation mode ('edit': an edit source given a source clip, audio=), so it runs through the same dispatch as every generation (foley.generate(): cost gate, budget, generations cache, safety screen, watermark, ingest, QC). What is particular to an edit lives here:

  • edit_lineage() — the mode’s licence gate, run by the generation workhorse before anything is paid for. An edit needs its source’s rights (derived_from=: the source’s SoundRecord, or its LicenseRecord); without them, or with rights that do not allow

    an edit (foley.licensing.derivative_refusal()), it is refused fail-closed (EditRefusal). This holds for foley.edit() and for a raw foley.generate(..., audio=...) alike.

  • EditLineage — what the edit derives from. It keys the request (an edit’s cache entry is never shared with another source or licence), and is applied to the new clip’s licence before the repair, the watermark, the credential and the ingest: the rights are narrowed to the source’s (foley.licensing.narrow_to_source()), and the edit (op, parameters, source id, content key, licence, credit) is appended to transformations, which the credits (foley.provenance.credits.derived_sources()) and the content credential (a parentOf ingredient) read.

  • resolve_edit() — what foley.edit() adds on top: the source sound from the library (its bytes, which must be sendable), the op and the backend (named, or the op’s default from the registry configs’ edit_op).

foley.sources.edit.edit_lineage(derived_from, *, config, affordances)[source]#

The gated EditLineage of an edit call: the edit mode’s licence gate (#162).

Run by the generation workhorse before anything is paid for, for every call of an edit source given its source clip (affordances['audio']).

Parameters:

  • derived_from (Union[SoundRecord, LicenseRecord, None]) – The source clip’s SoundRecord (what foley.edit() passes), or its LicenseRecord (a clip that is not in the library). Required.

  • config (dict) – The edit source’s config (its edit_op).

  • affordances (dict) – The call’s affordances (the clip, the op’s parameters).

Raises:

  • EditRefusal – Without derived_from; when its rights do not allow the edit (foley.licensing.derivative_refusal()); or when the clip sent is not the bytes of the derived_from record.

  • TypeError – For a derived_from that is neither record.

Return type:

EditLineage

foley.sources.edit.resolve_edit(source, op, prompt='', *, library, backend=None, adapter=None, affordances=None)[source]#

Resolve an edit of a library sound: its record, its op and its backend.

The op’s parameters and the source’s rights are checked by the generation’s edit mode itself (foley.sources._dispatch.translate_affordances(), edit_lineage()), before anything is paid for. Checked here is only what must be known before the source’s bytes are read from the library.

Parameters:

  • source (str) – The library id of the sound to edit.

  • op (str) – 'audio_to_audio' | 'inpaint' | 'extend' (foley.base.EDIT_OPS).

  • prompt (str) – What the edit should sound like; '': the source’s caption.

  • library – The SoundLibrary holding source.

  • backend (Optional[str]) – An edit source that does op; None: the injected adapter’s, else the op’s default (foley.sources.generate.default_edit_backend()), which is paid, so it needs paid generation opted in ($FOLEY_GENERATE_PAID=1; a key in the environment is not consent, #58).

  • adapter – An injected adapter (its config names the backend).

  • affordances (Optional[dict]) – The call’s other keywords (an audio= or derived_from= is refused: both come from the library).

Raises:

  • ValueError – For an unknown op, an audio= or derived_from=, or a backend that does another op.

  • KeyError – If source is not in library, or backend is unknown.

  • EditRefusal – If the source’s bytes may not be sent on (foley.licensing.upload_refusal(): a by-reference Freesound sound).

  • SourceConfigurationError – For an unnamed paid backend without the opt-in.

Return type:

EditCall
