foley.sources.elevenlabs.adapter#

ElevenLabs Sound Effects generate adapter — hosted Text-to-SFX v2 over HTTP.

Turns a natural-language prompt into a GeneratedClip via the ElevenLabs POST /v1/sound-generation endpoint (report 02 §ElevenLabs). The response is raw audio bytes (default MP3 44.1 kHz), stored by-value (the generation flywheel) once the foley.sources.generate.generate() façade routes it through ingest_one().

Two ElevenLabs-specific quirks the adapter handles:

  • ``output_format`` is a URL query parameter, not a JSON body field; everything else (text / model_id / prompt_influence / loop / duration_seconds) is the JSON body.

  • No seed / negative-prompt / step control — generation is non-deterministic, so generation_seed stays None and those unified affordances warn-and-drop.

HTTP is dependency-injected (a Transport), so the adapter is fully testable with no network and import foley stays dol-only; the real requests lives only behind requests_transport() (the foley[elevenlabs] extra). The adapter performs NO storage/library access — it builds the audio + a generated LicenseRecord and returns; the façade converges it on the shared ingest pipeline.

generate(prompt, *, duration=None, prompt_influence=None, negative_prompt=None, steps=None, seed=None, loop=False, output_format='wav', provider_params=None, **kw)[source]#

Generate a sound effect for prompt; return its bytes + provisional candidate.

Parameters:

  • prompt (str) – The natural-language sound description (required).

  • duration (Optional[float]) – Seconds (clamped to the native 0.5..30 range). None lets the model auto-determine the length from the prompt.

  • prompt_influence (Optional[float]) – 0..1 (identity map to the native field; higher = closer to the prompt, less variety). None (default) omits it, so the API applies its own default.

  • seed (Optional[int]) – No ElevenLabs SFX equivalent — a non-default value warns-and-drops (recorded in the clip notes); generation_seed stays None.

  • loop (bool) – Produce a seamless-loopable clip (native loop; v2 default).

  • output_format (str) – Coarse foley token (wav | opus | mp3) translated to the native enum; wav is the lossless pcm_48000 wrapped in a WAV header here, falling back to MP3 (with a note) if the account’s plan refuses PCM. Ingest re-archives to FLAC.

  • provider_params (Optional[dict]) – Native request fields merged over the translated ones (#61): JSON body fields, except output_format, which replaces the native format sent as the URL query param. Recorded in generation_params.

  • **kw – Extra/unknown affordances (warn-and-dropped).

invoke_native(*, params, body)[source]#

POST native params (URL query) and body (JSON) to the SFX endpoint.

The public entry below foley’s translation (#61): returns the transport’s response as is (.content holds the audio bytes, .headers the metadata). No plan/licence check and no dispatch-layer gate (cost authorization, egress, the generations cache) runs here: a caller of this method owns them, and pays for the call.

Raises:

RuntimeError – On a non-200 (an unbilled error carrying status_code and the best-effort detail).

property plan: str#

The account plan = the generated sound’s license_id (fail-closed when unknown).

It follows the key: a bound (per-request) key brings its own plan, and one bound without a plan is refused rather than labelled with the operator’s.
