foley.sources.music_library.acquisition#

Acquire a music library’s titles: verified files, one provenance row each, a resumable table.

acquire() turns titles into download URLs (the library’s rule), fetches each from the first of its mirrors whose bytes verify accepts, writes the file to out and returns one AcquiredTrack per title. Every step is a seam (keyword arguments with working defaults):

  • fetch (url -> bytes) or transport (a foley Transport): by default the fetch goes through make_fetch() (the resilience layer per

    host: pace, 429 / Retry-After, breaker); a fetch of the caller’s own is paced per host too (pace_per_host(), from the config’s rate). clock / sleep time both;

  • mirrors: direct(), then wayback();

  • verify (bytes -> seconds): probe_verify();

  • out: any {file name: bytes} store, a folder by default;

  • intended_use: the IntendedUse each title’s licence must allow (default foley.licensing.DEFAULT_INTENDED_USE: commercial publishing).

A row’s licence is a LicenseRecord (track_license()), put through foley’s fail-closed gate (foley.licensing.refusal_reason()) before anything is fetched: a title it refuses is a refused row, with the reason, and is not downloaded. url is where the bytes came from (the mirror that served them), page_url the library’s own address. A title that fails is a failed row with its reasons; the batch goes on. A file whose digest a previous run recorded (kept, from kept_digests() or kept_sources()) is not fetched again, so a rerun resumes. A paid library fetches nothing: its rows are wishlist rows.

AcquiredTrack.row() is a flat, JSON-safe dict (a caller such as an bridges it into its own asset rows without foley knowing it); tracks_table() is those rows as CSV, and attribution_text() the blocks to paste under a video.

foley.sources.music_library.acquisition.acquire(library, titles, *, out, fetch=None, transport=None, mirrors=(<function direct>, <function wayback>), verify=<function probe_verify>, kept=None, intended_use=IntendedUse(commercial=True, publish=True, redistribute_standalone=False, will_train=False, can_attribute=True, revenue_usd=0, allow_voice_or_trademark=False, territory=None), libraries=None, config=None, clock=<built-in function monotonic>, sleep=<built-in function sleep>)[source]#

Download titles of library into out, verified, one row each.

titles is a list, or {title: metadata} whose metadata (credited_by: the videos that credit it; a catalogue’s feel, genre, …) rides on the row. library is a MusicLibrary or a name in libraries (default MUSIC_LIBRARIES).

Each title’s licence is put through foley.licensing.refusal_reason() for intended_use first (fail-closed: an error in the gate is a refusal); a refused title is a refused row and is not fetched. The others are fetched from each of mirrors in turn until one gives bytes verify accepts. fetch (url -> bytes) replaces the HTTP path, paced per host by the config’s rate; otherwise the files come through transport (default: requests) wrapped by foley’s resilience layer per host; that path honours foley.offline(). config is laid over MUSIC_LIBRARY_HTTP; clock / sleep time the waits. kept is {file name: sha256} a previous run recorded (kept_digests()), or {file name: {"sha256", "url", "mirror"}} (kept_sources(), whose url and mirror the kept row keeps): a file in out with that digest is kept, any other is fetched again. A paid library downloads nothing and returns wishlist rows.

Raises:

  • MusicLibraryError – For an unknown library, titles of the wrong shape, metadata that restates the row, two titles saved as one file, or a kept value that is neither a digest nor a mapping with one.

  • MusicToolMissing – When verify is the default and no probe can run (before anything is downloaded).

  • ValueError – When both fetch and transport are given.

Return type:

list[AcquiredTrack]

foley.sources.music_library.acquisition.attribution_text(rows)[source]#

The attribution blocks to paste under a video, one per track that has one (acquired or kept), blank-line separated, each once.

Each block is foley.provenance.credits.attribution_line() of the row’s licence: the library’s own wording, verbatim.

>>> from foley.sources.music_library import MUSIC_LIBRARIES, track_license
>>> lic = track_license(MUSIC_LIBRARIES["incompetech"], "A")
>>> print(attribution_text([AcquiredTrack("A", "incompetech", ACQUIRED, lic)] * 2))
"A" Kevin MacLeod (incompetech.com)
Licensed under Creative Commons: By Attribution 4.0 License
http://creativecommons.org/licenses/by/4.0/
