foley.sources.music_library#

Acquire a licensed music library, with provenance: verified files, a tracks table, attribution.

A production that scores itself from free libraries writes the same script each time: turn the titles a channel credits into download URLs, fetch them politely, check each file is audio, record where it came from and under which licence, and collect the attribution lines the licence asks for. acquire() is that script:

from foley.sources.music_library import acquire, attribution_text, tracks_table

rows = acquire("incompetech", ["Sneaky Snitch"], out="audio/macleod")
open("audio/macleod/tracks.csv", "w").write(tracks_table(rows))
print(attribution_text(rows))

  • A library is data (MusicLibrary, MUSIC_LIBRARIES, register_music_library()): incompetech (Kevin MacLeod, CC BY 4.0) and

    the paid artlist and epidemic_sound, whose titles become wishlist rows.

  • Licences come from foley’s SSOT: each row’s LicenseRecord is built from the library’s licence URL by foley.licensing.license_id_from_cc_url() (track_license()) and gated

    by foley.licensing.refusal_reason() for acquire’s intended_use (default: commercial publishing) before anything is fetched; a refused title is a refused row. A paid library claims no rights.

  • Fetching is foley’s: a Transport wrapped per host by foley.sources.resilience.resilient() (pace, 429 / Retry-After, breaker), with the library’s own server then the Internet Archive’s raw copy as mirrors (direct(), wayback()); probe_verify() checks each file has an audio stream and a length, with foley’s media probes.

  • Rows are portable (AcquiredTrack): .row() is flat and JSON-safe, tracks_table() writes them as CSV and kept_digests() (or kept_sources(), with each file’s URL) reads a table back, so a rerun fetches

    only what it lacks.

  • Each free library is also a live retrieve source of its own name (#212): foley.add_from("incompetech", query="Sneaky Snitch") (a title, a list of titles, or a credits description) puts each title through the licence gate under the call’s intent and ingest_one(), giving by-value SoundRecord rows with their attribution, and a run manifest. The config is built from the library (library_source_config(), declared as the callable config.SOURCE_CONFIGS, so a library registered at runtime is a source on the next discovery); the adapter (MusicLibraryAdapter) runs the same mirror chain and verify as acquire(). A paid library is not a source.

Stdlib only at import; requests loads on the first real download.

>>> lib = MUSIC_LIBRARIES["incompetech"]
>>> lib.track_url("Sneaky Snitch")
'https://incompetech.com/music/royalty-free/mp3-royaltyfree/Sneaky%20Snitch.mp3'
>>> track_license(lib, "Sneaky Snitch").license_id
'CC-BY-4.0'

foley.sources.music_library.acquire(library, titles, *, out, fetch=None, transport=None, mirrors=(<function direct>, <function wayback>), verify=<function probe_verify>, kept=None, intended_use=IntendedUse(commercial=True, publish=True, redistribute_standalone=False, will_train=False, can_attribute=True, revenue_usd=0, allow_voice_or_trademark=False, territory=None), libraries=None, config=None, clock=<built-in function monotonic>, sleep=<built-in function sleep>)[source]#

Download titles of library into out, verified, one row each.

titles is a list, or {title: metadata} whose metadata (credited_by: the videos that credit it; a catalogue’s feel, genre, …) rides on the row. library is a MusicLibrary or a name in libraries (default MUSIC_LIBRARIES).

Each title’s licence is put through foley.licensing.refusal_reason() for intended_use first (fail-closed: an error in the gate is a refusal); a refused title is a refused row and is not fetched. The others are fetched from each of mirrors in turn until one gives bytes verify accepts. fetch (url -> bytes) replaces the HTTP path, paced per host by the config’s rate; otherwise the files come through transport (default: requests) wrapped by foley’s resilience layer per host; that path honours foley.offline(). config is laid over MUSIC_LIBRARY_HTTP; clock / sleep time the waits. kept is {file name: sha256} a previous run recorded (kept_digests()), or {file name: {"sha256", "url", "mirror"}} (kept_sources(), whose url and mirror the kept row keeps): a file in out with that digest is kept, any other is fetched again. A paid library downloads nothing and returns wishlist rows.

Raises:

  • MusicLibraryError – For an unknown library, titles of the wrong shape, metadata that restates the row, two titles saved as one file, or a kept value that is neither a digest nor a mapping with one.

  • MusicToolMissing – When verify is the default and no probe can run (before anything is downloaded).

  • ValueError – When both fetch and transport are given.

Return type:

list[AcquiredTrack]

foley.sources.music_library.fetch_audio(url, *, http, config=None)[source]#

url’s bytes, asked for with the config’s user agent.

A body over max_bytes is refused by its declared Content-Length before resp.content is touched, and by its length after (a server may declare none, or lie). foley’s Transport returns a whole response, so with requests_transport() the body is already in memory when the header is read: the header check spares the copy, not the download. A streaming transport, which would stop at max_bytes, is a follow-up.

Raises:

MusicLibraryError – On a non-200 answer, a text/* page (an error page served with 200), a body over config['max_bytes'], or one shorter than its declared Content-Length (a cut download, which a probe of its header alone would still accept).

Return type:

bytes

foley.sources.music_library.register_music_library(library, *, replace=False)[source]#

Add library to MUSIC_LIBRARIES (replace to redefine one).

A free library is checked for one licence right only, keeping the files (cache_bytes_ok); the uses a production makes of them are gated per title by acquire() (intended_use).

A library’s name is also its live-source name (foley.add_from(name, ...)), so it may not be the name of a source another foley.sources module declares, or one registered directly (openverse, freesound, a fal_* endpoint, …): that library would silently take the source over, or silently never become one.

Raises:

  • MusicLibraryError – If the name is taken (and not replace), or a free library has no track_url rule or a licence that does not allow keeping the files (a ShareAlike / NoDerivatives licence, refused on purpose; a licence URL foley cannot read; a licence whose flags say no).

  • SourceNameCollision – If the name is another module’s source name.

Return type:

None

foley.sources.music_library.titles_by_library(description, *, libraries=None)[source]#

The titles a video description credits, by library (default: the registered ones).

A line naming a library (by name or alias, with From/Music by/ Music: and a parenthetical allowed around it) opens its block, and each following line is a title until a blank line; a timestamp, a Song:/Track: label, quotes and bullets are stripped, and links and licence lines skipped. The attribution form ("Title" Kevin MacLeod (incompetech.com)) credits its title wherever it stands.

... - 0:00 Night Owl
... - Song: "Morning Light"
... https://www.epidemicsound.com/
...
... "Sneaky Snitch" Kevin MacLeod (incompetech.com)
... Licensed under Creative Commons: By Attribution 4.0 License'''
>>> titles_by_library(text)
{'epidemic_sound': ['Night Owl', 'Morning Light'], 'incompetech': ['Sneaky Snitch']}

foley.sources.music_library.track_license(library, title, *, page_url=None, sha256=None)[source]#

The LicenseRecord of title from library.

A free library’s record carries the id license_id_from_cc_url() reads from its licence URL, the flags derived from it (requires_attribution among them), rights_verified only where that id is verified, and the library’s attribution for the title. A paid library’s claims nothing: 'unknown', every flag closed, no attribution.

>>> rec = track_license(MUSIC_LIBRARIES["incompetech"], "A")
>>> rec.license_id, rec.requires_attribution, rec.commercial_ok, rec.rights_verified
('CC-BY-4.0', True, True, True)
>>> rec = track_license(MUSIC_LIBRARIES["artlist"], "A")
>>> rec.license_id, rec.commercial_ok, rec.rights_verified, rec.attribution_text
('unknown', False, False, None)

LicenseRecord
