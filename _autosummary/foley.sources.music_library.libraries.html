foley.sources.music_library.libraries#

Music libraries as data: who made one, its licence, its credit, where a title’s file is.

A MusicLibrary names its author, the URL of its licence, the attribution it asks for, the names a video credits it by, and the rule from a title to the file’s URL. The registry (MUSIC_LIBRARIES, register_music_library()) holds incompetech (Kevin MacLeod, CC BY 4.0) and two paid libraries, artlist and epidemic_sound, which have no free licence: their titles become wishlist rows to license by hand, never downloads.

The licence is never typed in: track_license() reads it from the library’s licence URL with foley.licensing.license_id_from_cc_url() (the one CC parser, which never widens rights) and builds the LicenseRecord with flags derived from that id. A free library whose licence does not let foley keep the files (cache_bytes_ok: a URL foley cannot read, or a ShareAlike / NoDerivatives licence, which foley refuses on purpose) is refused at registration (fail-closed), and a paid one claims no rights at all. Whether a title may be used for a production is acquire()’s intended_use gate, not registration’s.

>>> lib = MUSIC_LIBRARIES["incompetech"]
>>> lib.track_url("Sneaky Snitch")
'https://incompetech.com/music/royalty-free/mp3-royaltyfree/Sneaky%20Snitch.mp3'
>>> lib.license_id, lib.rights_verified
('CC-BY-4.0', True)
>>> print(lib.attribution_for("Sneaky Snitch"))
"Sneaky Snitch" Kevin MacLeod (incompetech.com)
Licensed under Creative Commons: By Attribution 4.0 License
http://creativecommons.org/licenses/by/4.0/

foley.sources.music_library.libraries.register_music_library(library, *, replace=False)[source]#

Add library to MUSIC_LIBRARIES (replace to redefine one).

A free library is checked for one licence right only, keeping the files (cache_bytes_ok); the uses a production makes of them are gated per title by acquire() (intended_use).

A library’s name is also its live-source name (foley.add_from(name, ...)), so it may not be the name of a source another foley.sources module declares, or one registered directly (openverse, freesound, a fal_* endpoint, …): that library would silently take the source over, or silently never become one.

Raises:

  • MusicLibraryError – If the name is taken (and not replace), or a free library has no track_url rule or a licence that does not allow keeping the files (a ShareAlike / NoDerivatives licence, refused on purpose; a licence URL foley cannot read; a licence whose flags say no).

  • SourceNameCollision – If the name is another module’s source name.

Return type:

None

foley.sources.music_library.libraries.track_license(library, title, *, page_url=None, sha256=None)[source]#

The LicenseRecord of title from library.

A free library’s record carries the id license_id_from_cc_url() reads from its licence URL, the flags derived from it (requires_attribution among them), rights_verified only where that id is verified, and the library’s attribution for the title. A paid library’s claims nothing: 'unknown', every flag closed, no attribution.

>>> rec = track_license(MUSIC_LIBRARIES["incompetech"], "A")
>>> rec.license_id, rec.requires_attribution, rec.commercial_ok, rec.rights_verified
('CC-BY-4.0', True, True, True)
>>> rec = track_license(MUSIC_LIBRARIES["artlist"], "A")
>>> rec.license_id, rec.commercial_ok, rec.rights_verified, rec.attribution_text
('unknown', False, False, None)
Return type:

LicenseRecord
