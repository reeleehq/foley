foley.sources.music_library.verify#

Checking a downloaded file is audio: an audio stream and a duration, read by foley’s probes.

probe_verify() is the default verify seam of acquire() (bytes -> seconds). It writes the bytes to a temporary file, checks it has an audio stream with foley.sources.video.has_audio_stream() (ffprobe, else soundfile), and reads its length with foley.sources.video.default_probe() (ffprobe, bounded by a timeout, else mixing’s probe): the probes foley uses for media, rather than a second ffprobe wrapper. An empty file, one with no audio stream (a video-only mp4, a gif), one whose audio stream cannot be confirmed (fail closed), and one with no readable duration (an error page saved as .mp3) are refused. require_probe() stops a batch before its first download when the checks cannot run.

foley.sources.music_library.verify.probe_verify(data, *, probe=None, has_audio=None, suffix='.mp3')[source]#

The duration of the audio data, in seconds.

The bytes are written to a temporary file named with suffix (from a pipe, ffprobe reports no duration). has_audio(path) -> True | False | None must say True (default has_audio_stream(); None, “cannot tell”, is a refusal), then probe(path) -> seconds | None reads the length (default default_probe()).
