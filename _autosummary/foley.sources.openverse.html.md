# foley.sources.openverse

Openverse retrieve source: keyless, licence-rich audio search (`foley[openverse]`).

Declares `SOURCE_CONFIG` (auto-discovered); the adapter loads lazily, so importing
this package stays dol-only.

### Classes

| `Adapter`                         |                                                                                                                                |
|-----------------------------------|--------------------------------------------------------------------------------------------------------------------------------|
| `OpenverseAdapter`([config, ...]) | Keyless Openverse adapter (a [`SourceAdapter`](foley.sources.base.html.md#foley.sources.base.SourceAdapter)). |

| [`config`](foley.sources.openverse.config.html.md#module-foley.sources.openverse.config)     | `SOURCE_CONFIG` for the Openverse retrieve source (#79 · report 14 §3.2).          |
