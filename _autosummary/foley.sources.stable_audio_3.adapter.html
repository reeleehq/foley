foley.sources.stable_audio_3.adapter#

Stable Audio 3 Small-SFX generate adapter: Stability’s TFLite CPU build, run as a process.

The model is not a pip package: Stability ships it as optimized/tflite in Stability-AI/stable-audio-3 (a script plus a requirements file, weights fetched on first use from the ungated stabilityai/stable-audio-3-optimized). The adapter drives that checkout’s scripts/sa3_tflite.py with the checkout’s own virtualenv Python, so foley takes on no dependency and import foley stays dol-only. Setup is two commands (setup_hint()); a missing checkout raises SourceConfigurationError with them, which the generation order treats as “skip this backend”.

  • Seam: runner= (runner(cmd, *, cwd, env, timeout) -> (returncode, stderr)) is the process boundary; a test injects a fake that writes the --out file.

  • Offline: the process runs with HF_HUB_OFFLINE=1 when the runtime forbids external egress, and a failure then raises ModelNotCached (foley never downloads weights inside foley.offline(), #86).

  • Seed: always passed (a random one when none is given) and recorded, so every clip is reproducible from its provenance.

  • Distilled: CFG 1; prompt_influence is noted and not applied (#70), and a negative prompt only acts when CFG is above 1, so it is dropped with a note.

generate(prompt, *, duration_s=None, prompt_influence=None, negative_prompt=None, steps=None, seed=None, loop=False, output_format='wav', provider_params=None, **kw)[source]#

Generate a sound for prompt on the CPU; return its bytes + provisional candidate.

duration_s is clamped to the model’s 1..120 s (default 10 s); the model renders whole latent frames, so the clip may differ from it by a few milliseconds. seed=None draws a random seed, recorded in the clip’s provenance (the script always takes one). Through foley.generate() the dispatch layer has already drawn it (foley.sources._dispatch.draws_seed(), #206); this draw serves a direct call. provider_params (#61) are native script flags merged over the translated ones (seconds, steps, cfg, seed; any other key is passed as --<key> <value>) and recorded in generation_params; the config’s provider_params policy refuses the prompt, output path and model flags.

Return type:

GeneratedClip

invoke_native(prompt, native)[source]#

Run the script with native flags into a temp file; return the WAV bytes it wrote.

The public entry below foley’s translation (#61): each native key (the script’s seconds / steps / cfg / seed, or any other flag) becomes a --<key> <value> flag, followed by foley’s own --dit / --decoder / --prompt / --out. No licence record is built and no dispatch-layer check runs (cost, egress): a caller owns those.
