foley.weave#

WEAVE — the compositor façade: narration + timeline → a finished, editable mix.

weave() is the headline WEAVE entrypoint (report 06 §7, issue #8): it resolves the master profile, binds the narration, opens a foley.obs.run('weave') scope, and drives the PURE render() pipeline (align → anchor → mix → master → render), then wraps the result with credits, SDH captions, and a fail-safe provenance re-assertion over the mastered mix. It returns a WeaveResult: the mastered audio, the hydrated re-renderable SoundDesignTimeline (the reproducible seed), a Credits, WebVTT + SRT SDH captions, the master report, and the run-artifact join.

Discipline (mirrors the rest of foley): the whole package is import-time dol-only (numpy / mixing.loudness / whisperx / opentimelineio / audioseal / c2pa are all function-local), the aligner and per-item strategy are injectable DI seams with deterministic defaults, and provenance re-assertion never raises — the C2PA content-credential sidecar is always emitted; the AudioSeal watermark and the (deferred) signed + embedded C2PA manifest are best-effort no-ops when their extras/cert are absent.

class foley.weave.Aligner(*args, **kwargs)[source]#

Bases: Protocol

Narration audio + its transcript → word-level timestamps (forced alignment).

Returns a word_timeline: a list of {'word': str, 'start': float, 'end': float} dicts (seconds), the raw material the anchor heuristics (report 06 §2.4) turn into sample onsets. The default is the deterministic, torch-free FakeAligner (evenly spaces the transcript’s words across the clip); WhisperXAligner is the real ≈±50 ms impl behind foley[align].

class foley.weave.ApplyStrategy(*args, **kwargs)[source]#

Bases: Protocol

How ONE hydrated item’s clip is placed onto its layer bus (report 10 §4.2).

The seam that lets the render swap placement policy without touching the render loop: the default FullRender applies the full per-item DSP chain (fit-duration → gain/pan/distance/reverb → declick → overlay), while PlaceOnly does a dry declicked overlay (fast preview / DSP-free fallback). item is already anchor-resolved (item.placement.onset is in seconds); bus and clip are stereo float32 working arrays at sample_rate. A strategy with settings that change its output should expose them as a cache_key string: the RenderCache keys on it (default: the class name).

class foley.weave.FakeAligner[source]#

Bases: object

Deterministic, torch-free Aligner — evenly spaces the transcript’s words.

The hermetic default: given a transcript, it returns one {'word','start','end'} per whitespace token, spread uniformly across the clip’s duration (or at WORDS_PER_SECOND when the audio is empty). No transcript → an empty word_timeline (the render then falls back to absolute anchors).

class foley.weave.FullRender(*, level_clips=True)[source]#

Bases: object

Default ApplyStrategy — the full per-item DSP chain (report 06 §3-4).

fit-duration (loop/trim) → level (measured loudness to the reference, foley.level.reference_gain_db(), on what will be heard) → distance → reverb send → constant-power pan → declick → gain (base layer level + item gain_db) → overlay at the resolved onset. Levelling first means the layer gains act on clips of equal loudness, whatever level each was generated or recorded at (#111); level_clips=False renders the clips as stored.

property cache_key: str#

What distinguishes this strategy’s output in RenderCache keys.

class foley.weave.MasterProfile(target_lufs=-16.0, true_peak_db=-1.0, lra=11.0, max_limiting_db=6.0)[source]#

Bases: SerializableMixin

Loudness master target — the delivery spec as data, not code (report 06 §5.2).

max_limiting_db: float = 6.0#

How far (dB) the master’s loudness stage lets the sample peak run over true_peak_db for the default lookahead limiter to take back (it may take off a little more, the inter-sample overshoot of those peaks). 0 restores a static, whole-program master. Transient foley (a door slam under narration) needs a few dB to reach the target at all (foley#91).

foley.weave.hydrate(timeline, word_timeline=None)[source]#

Resolve every item’s anchor + fill processing/id, returning a NEW timeline.

Idempotent: an item that already carries a Placement keeps its symbolic anchor (a hand edit is never clobbered) but is re-resolved against word_timeline so a re-recorded/re-aligned narration re-flows the SFX (report 06 §6.1). processing falls back to the sparse gain and id to a stable content hash. The resolved word_timeline is cached on the returned timeline (the reproducible seed).

Parameters:

  • timeline (SoundDesignTimeline) – The (sparse or partially-resolved) timeline.

  • word_timeline (Optional[list]) – The forced alignment; defaults to timeline.word_timeline.

Return type:

SoundDesignTimeline

Returns:

A hydrated copy with resolved placements, filled processing, stable ids.

foley.weave.nudge(timeline, item_id, delta_s)[source]#

Shift an item’s resolved onset by delta_s seconds — a NEW timeline.

Resolves the item’s anchor against the timeline’s word_timeline first, then shifts the resolved onset and pins the anchor to absolute so the manual offset survives a re-hydrate. This means nudging a still-symbolic (not-yet-hydrated) item on a timeline that carries alignment shifts from the item’s true resolved onset, not from 0. On a pre-alignment timeline with no word_timeline a word/sentence anchor is genuinely unresolvable, so there the shift is relative to 0 — hydrate/weave first for such items.

Return type:

SoundDesignTimeline

foley.weave.parse_symbolic_anchor(onset, *, layer=Layer.sfx_fg, loop=False)[source]#

Parse SELECT’s sparse symbolic onset string into a resolved-later Placement.

The anchor type follows the item’s role (report 06 §2.4): beds (loop / ambience / music) span a sentence, stingers land on a scene boundary, and everything else is a word anchor; the ref is the quoted phrase the sound lands on. A None onset means “no cue”: beds span from the start, one-shots sit at absolute 0. A bare number (defensive — SELECT is told never to emit one) is read as an absolute offset in seconds.

Parameters:

  • onset (Optional[str]) – The symbolic anchor string (e.g. "on 'pushed open'") or None.

  • layer (Layer) – The item’s mix layer (selects span/boundary vs word anchoring).

  • loop (bool) – Whether the item is a looping bed (span-anchored).

Return type:

Placement

Returns:

A Placement whose onset (seconds) is resolved later by resolve_anchor() against the word_timeline.

Re-assert provenance over the mastered mix — watermark + C2PA sidecar (fail-safe).

Watermarks the final mix when it carries AI-generated audio (or when watermark=True), always writes a mix-level C2PA content-credential sidecar, and best-effort signs+embeds it. Never raises: any failure degrades to sidecar-only, so weaving is never blocked by provenance.

foley.weave.resolve_anchor(placement, word_timeline, *, snap_pauses=False)[source]#

Resolve a Placement to a concrete (onset_seconds, duration_seconds).

Dispatches on placement.anchor (report 06 §2.4): absolute uses the stored offset; word fires on the trigger word; sentence spans its sentence (filling duration when unset — beds loop to fill it); scene / paragraph land on the boundary. pre_roll is then subtracted (clamped at 0), and — when snap_pauses — the onset snaps to the nearest inter-word gap.

Parameters:

  • placement (Placement) – The symbolic placement to resolve.

  • word_timeline (list[dict]) – The forced-aligned [{'word','start','end'}, ...].

  • snap_pauses (bool) – If True, snap the resolved onset to the nearest pause.

Return type:

tuple[float, Optional[float]]

Returns:

(onset_seconds, duration_seconds_or_None). duration is filled only for a span anchor whose placement.duration was unset.

foley.weave.to_otio(timeline, *, rate=25)[source]#

Export timeline as an OpenTimelineIO JSON string (lazy foley[weave]).

One or more parallel tracks per non-voice layer: each enabled, placed item is a clip with an external media reference (by clip_ref), positioned at its resolved onset via a leading gap. Because a single OTIO track is sequential, two same-layer clips that overlap (or fall within a one-shot’s nominal window) would otherwise be pushed late — so overlapping clips spill onto sibling sub-tracks, keeping every clip at its true onset. Non-destructive, minimal-viable fidelity (tracks/clips/onsets; effects/markers are a later slice).

Raises:

RuntimeError – If opentimelineio is not installed.

Return type:

str

foley.weave.weave(narration, timeline, *, master='podcast', library=None, transcript=None, aligner=None, apply_strategy=None, sr=48000, cache=None, watermark=None, watermarker=None, sign_cert=None, export_captions=True, provenance_store=None)[source]#

Weave the chosen sounds under narration into a mastered, editable mix.

The headline WEAVE façade (v1 DoD): foley.weave(narration, timeline) → align → anchor → mix → master → render, plus credits, SDH captions, and a reproducible run-artifact. Works out of the box with deterministic defaults (a fake aligner + pure-numpy DSP + in-process mastering); every model / seam is an optional keyword.

Parameters:

  • narration – The voice audio — a path / bytes / file-like / working ndarray, or a ref already keyed in library.

  • timeline (SoundDesignTimeline) – The (sparse) SoundDesignTimeline from foley.plan(); WEAVE resolves anchors and fills processing.

  • master (Union[str, MasterProfile]) – A MASTER_PROFILES name ('podcast' default) or a MasterProfile.

  • library – The foley.index.SoundLibrary (or a mapping) holding the clips.

  • transcript (Optional[str]) – The narration transcript, for forced alignment (skipped when the timeline already carries a word_timeline).

  • aligner (Optional[Aligner]) – The forced-alignment seam (default: WhisperX if installed, else fake).

  • apply_strategy (Optional[ApplyStrategy]) – The per-item placement seam (default FullRender).

  • sr (int) – Working/render sample rate in Hz.

  • cache (Optional[RenderCache]) – An optional RenderCache for incremental re-render.

  • watermark (Optional[bool]) – True force a watermark, False never, None (default) auto — watermark iff the mix contains AI-generated audio and AudioSeal is installed.

  • watermarker – An injected watermarker (the DI seam; tests pass a fake).

  • sign_cert – A ready c2pa.Signer for the signed+embedded C2PA path (build one with foley.provenance.make_c2pa_signer()); omit for the sidecar only.

  • export_captions (bool) – If True (default), emit WebVTT + SRT SDH captions.

  • provenance_store – An optional MutableMapping to persist the C2PA sidecar.

Return type:

WeaveResult

Returns:

A WeaveResult.
